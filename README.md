# Автоматизация товарного учёта (VBA / Excel)

Учебный проект: приложение на VBA для сбора, хранения и редактирования данных о товарах с автоматическим расчётом стоимости и скидок в зависимости от срока годности.

## Проблема

Ручной учёт товаров в Excel занимает время и приводит к ошибкам: нужно вручную пересчитывать стоимость партии, отслеживать сроки годности и вовремя применять скидки на товары, которые скоро испортятся.

## Решение

Разработано VBA-приложение, которое автоматизирует эти операции:

- **Ввод товаров через UserForm** — удобная форма вместо ручного заполнения строк.
- **Автоматический расчёт стоимости** — сумма по каждой позиции и итог по всем товарам.
- **Расчёт скидок по сроку годности** — при проверке на указанную дату:
  - срок годности больше 2 дней → скидка 0%;
  - срок годности 2 дня и меньше → скидка 20%, строка подсвечивается жёлтым;
  - товар просрочен → строка подсвечивается красным, скидка и новая цена не рассчитываются.
- **Редактирование и удаление** — по номеру строки через диалоговые окна.
- **Валидация ввода** — проверка корректности данных при добавлении товара.

## Возможности программы

| Функция | Описание |
|---|---|
| Инициализация таблицы | Создание шапки с нужными колонками и шириной столбцов |
| Добавление товара | UserForm с полями: наименование, ID, масса, жирность, количество, даты, изготовитель, стоимость |

| Редактирование | Изменение количества, дат и стоимости по номеру строки |
| Удаление | Очистка строки по номеру |

## Как запустить

1. Скачайте файл `Товарный_учет.xlsm`.
2. Откройте его в Microsoft Excel.
3. Разрешите выполнение макросов (кнопка «Enable Content» / «Разрешить содержимое»).
4. Нажмите кнопку **«Инициализировать таблицу»** — создастся шапка.
5. Для добавления товара нажмите **«Добавить товар»** и заполните форму.

## Основные компоненты

- **Лист Excel «Товары»** — хранит данные в табличном виде, содержит кнопки вызова функций.
- **UserForm «Products»** — форма ввода: текстовые поля, выпадающий список изготовителей, кнопки «ОК» и «Отмена».
- **Модули VBA** — обработчики событий кнопок, функции валидации, логика расчётов (стоимость, скидка, просрочка).
